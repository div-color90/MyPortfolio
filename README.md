## What Is Multiplatform Application Development (DAM)?

DAM is a two-year Higher Vocational Education and Training programme in Spain (EQF Level 5). It prepares students to design, develop, test, and maintain software applications for different platforms.

The programme combines programming fundamentals with practical software development, databases, user interfaces, mobile applications, and software deployment.

### What Do Students Learn?

The programme covers several areas of software development:

- **Programming:** Learning programming logic, algorithms, object-oriented programming, and languages such as Java and Kotlin.
- **Databases and Data Access:** Designing databases, working with SQL and PostgreSQL, and developing applications that store and retrieve information.
- **Markup Languages and Information Management:** Working with HTML, XML, and other technologies used to structure and exchange information.
- **Development Environments:** Using IDEs, version control systems, debugging tools, and software development workflows.
- **Computer Systems:** Understanding operating systems, computer hardware, networks, and system administration fundamentals.
- **User Interface Development:** Designing and implementing graphical interfaces, focusing on usability and user experience.
- **Multimedia and Mobile Application Development:** Creating applications for mobile devices and working with multimedia technologies.
- **Programming Services and Processes:** Developing applications that communicate with other systems and manage different processes.
- **Enterprise Resource Planning (ERP) and Customer Relationship Management (CRM):** Understanding business management software and how companies use these systems.
- **Deployment and Application Management:** Preparing applications for installation, deployment, and maintenance.

The programme also includes professional training, project work, and preparation for working in a software development environment. Specific modules may vary depending on the curriculum and academic year.
